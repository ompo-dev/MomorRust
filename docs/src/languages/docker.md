# Docker

Support for `Dockerfile` and `docker-compose.yaml` in Momor is provided by community-maintained extensions.

## Docker Compose

Docker `compose.yaml` language support in Momor is provided by the [Docker Compose extension](https://github.com/eth0net/momor-docker-compose). Please report issues to: [https://github.com/eth0net/momor-docker-compose/issues](https://github.com/eth0net/momor-docker-compose/issues).

- Language Server: [microsoft/compose-language-service](https://github.com/microsoft/compose-language-service)

## Dockerfile

`Dockerfile` language support in Momor is provided by the [Dockerfile extension](https://github.com/d1y/dockerfile.momor). Please report issues to: [https://github.com/d1y/dockerfile.momor/issues](https://github.com/d1y/dockerfile.momor/issues).

- Tree-sitter: [camdencheek/tree-sitter-dockerfile](https://github.com/camdencheek/tree-sitter-dockerfile)
- Language Server: [rcjsuen/dockerfile-language-server](https://github.com/rcjsuen/dockerfile-language-server)
