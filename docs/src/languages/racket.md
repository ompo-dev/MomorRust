# Racket

Racket support is available through the [Racket extension](https://github.com/momor-extensions/racket).

- Tree-sitter: [momor-industries/tree-sitter-racket](https://github.com/momor-industries/tree-sitter-racket)

The [racket-language-server](https://docs.racket-lang.org/racket-language-server/index.html) is not yet supported in Momor, please see [Issue #15789](https://github.com/momor-industries/momor/issues/15789) for more information.
