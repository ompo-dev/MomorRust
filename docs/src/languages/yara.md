# Yara

`Yara` language support in Momor is provided by the [Yara language extension](https://github.com/egibs/yara.momor). Please report issues to [https://github.com/egibs/yara.momor/issues](https://github.com/egibs/yara.momor/issues).

- Tree-sitter: [egibs/tree-sitter-yara](https://github.com/egibs/tree-sitter-yara)
- Language Server: [avast/yls](https://github.com/avast/yls)
